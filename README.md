# AIアイコン展示ページ

`index.html` をブラウザで開くと、AIの入力・確認・送信・同期などのアニメーションと、3種類のSVGカーソルを確認できます。

## ファイル
- `index.html`: 展示ページ
- `cursor.css`: カスタムカーソル定義
- `cursors/ai-pointer.svg`: 通常カーソル
- `cursors/ai-busy.svg`: 処理中カーソル
- `cursors/ai-success.svg`: 完了カーソル

GitHub Pagesでは、このフォルダの内容をリポジトリ直下または公開対象フォルダに置けば表示できます。

## アニメーションカーソル

通常の cursor: url() は静止画ですが、展示ページではマウス位置に追従する発光カーソルを重ねてアニメーションさせています。処理中は黄色、完了は緑色です。ページ上部の「アニメーション再生」で停止・再生を切り替えられます。
